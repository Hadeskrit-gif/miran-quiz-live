# Викторина про Мирашу, версия для гостей

- `index.html` — страница игроков (телефон): имя, вопросы с таймером 30 секунд, итоговые баллы.
- `admin.html` — экран ведущего (ноутбук или ТВ): вопросы с таймером, разбор ответов, таблица результатов.
- `data.js` — вопросы, ответы и настройки (время на ответ, канал для результатов).

Результаты игроков уходят через ntfy.sh в канал из `data.js` (хранятся 12 часов). Для проверок: `?t=любой-канал` и `?lim=5` (секунд на вопрос), `?reset=1` на странице игрока сбрасывает прохождение.
